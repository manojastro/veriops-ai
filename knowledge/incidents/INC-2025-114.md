# INC-2025-114: checkout latency after ORM query change

## Summary
After deployment #771 changed an order lookup to filter on a function of an indexed column, the query
switched to a sequential scan. Mean query time rose 11x, the orders-db pool saturated, p95 latency
reached 3.8 s and errors 9%.

## What went wrong in the response
The first responder scaled checkout-service from 3 to 10 replicas. Total connections exceeded
orders-db max_connections and error rate doubled. The incident resolved only after rolling back #771.

## Resolution
Rolled back deployment #771. Latency recovered within 3 minutes.

## Preventive actions
EXPLAIN plans required for ORM changes; alert on per-query regression.
