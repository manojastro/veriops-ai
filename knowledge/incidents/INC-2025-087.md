# INC-2025-087: inventory latency after cache TTL change

A config change set `cache.ttl_seconds` to 0 while debugging stale stock. Cache hit ratio dropped to
zero, inventory-db QPS rose 7x and p95 latency reached 1.6 s. Resolution: reverted the TTL to 300.
